### 检测内容

| 检测项 | 说明 |
|--------|------|
| can_tma_load | 能否使用 TMA 加载 |
| can_tma_store | 能否使用 TMA 存储 |
| can_copy | 能否使用普通 copy |
| can_lds_matrix | 能否使用 LDS matrix |
| can_sts_matrix | 能否使用 STS matrix |
| user_disable_tma | 用户是否禁用了 TMA |
| user_request_tma | 用户是否显式请求 TMA |

### 决策逻辑

- 不 disable TMA → 系统自动选最优（"顺丰" = TMA）
- 显式 disable TMA → 回退到其他方式（"圆通" = cp.async 等）
- 通过不同 check 函数筛选 → 最终决定搬运方式

### 同步 vs 异步搬运

| 模式 | 行为 | 类比 |
|------|------|------|
| **同步** | 发起搬运 → 等待完成 → 继续执行 | 叫外卖 → 在门口等骑手 → 拿到才回去工作 |
| **异步** | 发起搬运 → 立即继续 → 某时检查完成 | 叫外卖 → 继续写代码 → 看手机通知 → 去取 |

### 异步搬运的核心价值

```
搬运与计算 Overlap → 不浪费等待时间
```

- 代价：使用数据前**必须确认**搬运已完成

### Barrier 工作原理（信号灯类比）

```
① 申请 Barrier（创建信号灯）
② 发起异步搬运（告诉硬件：搬完点亮信号灯）
③ 继续执行其他计算
④ 在 Barrier 处等待（检查信号灯）
   ├─ 灯亮 → 搬运完成 → 继续
   └─ 未亮 → 阻塞等待
```

### TileLang 写法

```python
T.copy(source, shared)   # Global → Shared
T.copy(shared, local)    # Shared → Local
```

> 只需指定 source 和 destination，编译器自动处理一切

### CUTLASS 写法（手动操作）

| 步骤 | 内容 |
|------|------|
| ① 构建张量视图 | 手动创建全局 Tensor View |
| ② Block 切分 Tile | 按 Grid → Block → Warp 层级切分 |
| ③ 越界检查 | 手动构建 Predicate 检查边界 |
| ④ 选择 Copy 原语 | 手动选择 Copy_Atom（原子级搬运） |
| ⑤ 向量化宽度 | 手动指定 unit_bytes |
| ⑥ 线程布局 | 手动构建 Tile 的线程分布 |
| ⑦ 线程切分 | 为每个 Thread（32 threads/warp）分配工作 |
| ⑧ Fragment 缓冲 | 分配中间缓冲区 |
| ⑨ Host 端对齐检查 | 检查对齐、计算 Grid/Block 维度 |

### 对比总结

| 维度 | TileLang (T.copy) | CUTLASS |
|------|-------------------|---------|
| 代码量 | 1 行 | 数十行 |
| 手动程度 | 全自动 | 全手动 |
| 越界检查 | 编译器自动 | 手动 Predicate |
| 向量化 | 编译器推断 | 手动指定 |
| 线程布局 | 编译器推断 | 手动构建 |
| 跨硬件 | 自动适配 | 需改 layout |

### 要点

- MetaX **也支持** CUTLASS 库
- 需要修改 **layout**（数据布局）
- 部分算子：只需改 output layout → 即可在 MetaX 上达到最佳性能
- 部分算子：需要更深入理解 MetaX 编程模型

### CUTLASS 搬运的本质（归根结底）

```
手动构造 Tensor View
→ 按 Block 切分 Tile
→ 构建 Predicate（越界检查）
→ 选择 Copy 原语 + 向量化宽度
→ 指定线程布局 + 值布局
→ 手动切分每个 Thread 的工作
→ 分配 Fragment 缓冲
→ Host 端检查对齐 + 计算 Grid/Block 维度
```

> 这些手动操作在 TileLang 中全部由**编译器自动完成**

## Key Terms

| 术语 | 含义 |
|------|------|
| Analyzed Copy Factor | 搬运能力检测结构体，判断可用哪种搬运方式 |
| Barrier | 同步原语（屏障/信号灯），用于异步搬运的完成通知 |
| 异步搬运 | 发起后立即继续执行，通过 Barrier 确认完成 |
| Overlap | 搬运与计算重叠执行，消除等待时间 |
| CUTLASS | NVIDIA 的 C++ 模板库，用于高性能 GEMM 等操作 |
| Copy_Atom | CUTLASS 中的原子级搬运操作 |
| Predicate | 越界检查条件，防止 Tile 切分后访问越界 |
| Fragment | 线程私有的中间缓冲寄存器 |
| memcpy_async | MetaX 的异步内存拷贝指令 |
| Tile | 按 Block 层级切分后的数据子块 |
